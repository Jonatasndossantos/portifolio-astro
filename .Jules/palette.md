
## 2024-05-18 - Keyboard Navigation in Astro View Transitions
**Learning:** When attaching event listeners to the global `window` or `document` object inside Astro components, specifically when using `astro:page-load` or inline script tags in Astro View Transitions, it is crucial to handle duplication. Simple `document.removeEventListener` followed by `document.addEventListener` does not work reliably if the listener is defined as an anonymous/arrow function inside the `<script>` tag. The script tag will execute multiple times (once per navigation), and each time a new anonymous function is created in memory, failing the removal check.
**Action:** When implementing global keyboard shortcuts (e.g. `/` for search focus), store a boolean flag on the global `window` object (e.g. `if (!window.hasAttachedSearchFilterShortcut)`) to ensure the listener is bound only once for the entire session. Alternatively, extract the logic into a separate module or standard `<script src="...">` that executes once.
