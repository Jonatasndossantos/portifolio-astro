## 2024-09-04 - [Global Search Discoverability]
**Learning:** [Power users rely heavily on keyboard shortcuts for navigation. Adding a visible `<kbd>` hint and a `keydown` listener to instantly focus global search inputs significantly reduces friction and improves efficiency.]
**Action:** [When implementing global search bars, always add a visible keyboard shortcut hint (e.g., `<kbd>/</kbd>`) and a `keydown` event listener to focus the input.]
