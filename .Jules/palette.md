## 2023-10-27 - [Async Submit Buttons UX Improvement]
**Learning:** For asynchronous form submissions, users rely on visual and auditory cues to understand that the request is in flight. A button with a hidden spinner and `aria-live="polite"` attribute provides immediate visual feedback (e.g. DaisyUI `loading-spinner`) while correctly communicating state changes to assistive technologies like screen readers, which reduces user frustration or double submissions.
**Action:** Always include a visual loading state (like a spinner) inside async submit buttons. Combine this with `aria-live="polite"` or `aria-disabled` on the element so screen reader users are notified when the state updates during API calls or form processing. Use Vanilla JS to toggle these states independently of React hydration.
