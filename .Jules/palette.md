## 2024-02-18 - Async Submit Button UX\n**Learning:** Providing explicit visual feedback (like a loading spinner and hiding the default icon) alongside `aria-live="polite"` on async submission buttons significantly improves both accessibility and user confidence during flight states. It prevents multiple submissions and communicates the state effectively to screen readers.\n**Action:** Always use a combination of `loading-spinner`, hidden default icons, and `aria-live="polite"` for async submission buttons to ensure clear state communication for all users.
