## 2024-05-20 - Global Keyboard Search Shortcut
**Learning:** Adding absolute positioned `<kbd>` tags inside an `<input>` parent wrapper requires manually bumping up the input padding (e.g. `pr-[70px]`) so typed text does not go under the shortcut hint. Also, when binding `keydown` to the document for global shortcuts, always check `document.activeElement?.tagName` to avoid hijacking normal typing in textareas or inputs. Finally, Astro scripts might run multiple times or not unmount correctly with view transitions, so wrap global listeners in a teardown via `astro:before-swap`.
**Action:** When creating global search shortcuts in Astro + DaisyUI, use `<kbd>` for visual hints, pad the input text area to accommodate it, exclude inputs/textareas in the keydown handler, and unbind the listener on page swap if defined inside a component.
