## 2024-05-18 - Keyboard shortcut hint for global search
**Learning:** Adding a visible keyboard shortcut hint (e.g., `<kbd>/</kbd>`) to search inputs and binding a global `keydown` event listener greatly improves accessibility and keyboard navigation for power users.
**Action:** Implement a keyboard shortcut listener in the search page and layout components, displaying a subtle hint inside the input box to improve usability.
